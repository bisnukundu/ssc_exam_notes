৬Unit 6 — Conditional sentence (p. 63–72)Unit
সহজ ব্যাখ্যা:
A conditional sentence has two parts: the 'if-clause' (the condition) and the main clause (the result). (Conditional = শর্তসাপেক্ষ বাক্য।) There are three main types. Type 1 is a real condition in the future: If + Present Indefinite, will + base verb. Type 2 is an unreal condition in the present: If + Past Indefinite, would + base verb. Type 3 is an unreal condition in the past: If + Past Perfect, would have + past participle.

গুরুত্বপূর্ণ পয়েন্ট:
• Zero conditional (general truth): If + Present, Present — 'If water is heated, it boils.'
• Type 1: 'If it rains, we will stay at home.'
• Type 2: 'If I were rich, I would help the poor.' (Note: 'were' is used with all persons.)
• Type 3: 'If you had studied, you would have passed.'

পরীক্ষার প্রস্তুতি:
Conditional sentences are a regular Grammar item. First look at the tense of the if-clause, then choose the main clause to match it. Common mistakes: using 'will' in the if-clause ('If it will rain' is wrong), and using 'would' instead of 'would have' in Type 3. Learn the four patterns by heart with one example each.

Quick Revision:
Zero: if + present, present. Type 1: if + present, will. Type 2: if + past, would. Type 3: if + had + pp, would have + pp.
