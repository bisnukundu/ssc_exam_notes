২Unit 2 — বীজগাণিতিক রাশি (পৃ. ৩১–৫৪)Unit
সহজ ব্যাখ্যা:
বীজগাণিতিক রাশি হলো চলক, ধ্রুবক ও গাণিতিক চিহ্ন দিয়ে গঠিত প্রকাশ, যেমন 3x^2 + 2x - 5। যে রাশিতে শুধু x-এর পূর্ণসংখ্যা ঘাত থাকে, তাকে বহুপদ বলে। বহুপদের মাত্রা হলো চলকের সর্বোচ্চ ঘাত। যেমন 3x^3 + 2x-এর মাত্রা 3। উৎপাদকে বিশ্লেষণ মানে রাশিকে গুণনীয়কের গুণফল আকারে লেখা, যেমন x^2 - 9 = (x - 3)(x + 3)।

গুরুত্বপূর্ণ পয়েন্ট:
• গুরুত্বপূর্ণ সূত্র: (a + b)^2 = a^2 + 2ab + b^2; (a - b)^2 = a^2 - 2ab + b^2; a^2 - b^2 = (a - b)(a + b); a^3 + b^3 = (a + b)(a^2 - ab + b^2); a^3 - b^3 = (a - b)(a^2 + ab + b^2)।
• উৎপাদকে বিশ্লেষণের পদ্ধতি: সাধারণ উৎপাদক বের করা, সূত্র প্রয়োগ, মধ্যপদ বিভাজন (যেমন x^2 + 5x + 6 = (x + 2)(x + 3))।
• ভাগশেষ উপপাদ্য: বহুপদ f(x)-কে (x - a) দিয়ে ভাগ করলে ভাগশেষ f(a) হয়।; f(a) = 0 হলে (x - a), f(x)-এর একটি উৎপাদক।

পরীক্ষার প্রস্তুতি:
MCQ-তে উৎপাদকে বিশ্লেষণ, মধ্যপদ বিভাজন ও ভাগশেষ নির্ণয় থেকে প্রশ্ন আসে বেশি। (a - b)^2-এর সূত্রে মাঝের চিহ্ন বিয়োগ হয় — এটাই সবচেয়ে বেশি ভুল হয়। ভাগশেষ বের করার সময় x-এর জায়গায় a বসিয়ে f(a) হিসাব করবে। উৎপাদক ঠিক হয়েছে কি না তা গুণ করে যাচাই করবে।

Quick Revision:
বহুপদের মাত্রা = চলকের সর্বোচ্চ ঘাত; a^2 - b^2 = (a - b)(a + b); ভাগশেষ উপপাদ্য: (x - a) দিয়ে ভাগ করলে ভাগশেষ f(a); f(a) = 0 হলে (x - a) উৎপাদক।

✅ সঠিক উত্তর: (x - 3)(x + 3)
