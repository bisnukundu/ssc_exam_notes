৫Unit 5 — অসীম ধারা (পৃ. ৯৭–১০৬)Unit
সহজ ব্যাখ্যা:
ধারা হলো সংখ্যার একটি ক্রম, যেমন 2, 5, 8, 11, ...। সমান্তর ধারায় পরপর দুটি পদের পার্থক্য সমান থাকে; সেই পার্থক্যকে সাধারণ অন্তর d বলে। যেমন 2, 5, 8, ... ধারায় d = 3। গুণোত্তর ধারায় পরপর দুটি পদের অনুপাত সমান থাকে; সেই অনুপাতকে সাধারণ অনুপাত r বলে। যেমন 2, 4, 8, 16, ... ধারায় r = 2।

গুরুত্বপূর্ণ পয়েন্ট:
• সমান্তর ধারা: n তম পদ = a + (n - 1)d; প্রথম n পদের সমষ্টি = n/2 {2a + (n - 1)d}।
• গুণোত্তর ধারা: n তম পদ = a × r^(n - 1); প্রথম n পদের সমষ্টি = a(r^n - 1)/(r - 1), যেখানে r ≠ 1।
• অসীম গুণোত্তর ধারার সমষ্টি = a/(1 - r), শুধু যখন |r| < 1।

পরীক্ষার প্রস্তুতি:
MCQ-তে n তম পদ, প্রথম n পদের সমষ্টি ও অসীম ধারার সমষ্টি থেকে প্রশ্ন আসে বেশি। সূত্রে n-এর জায়গায় সঠিক সংখ্যা বসাবে — ১০ম পদের জন্য n = 10, (n - 1) = 9। অসীম ধারার সমষ্টির সূত্র শুধু |r| < 1 হলে প্রযোজ্য, r = 2 হলে অসীম ধারার সমষ্টি বের করা যায় না — এটা মনে রাখবে। সমষ্টির সূত্রে বন্ধনীর হিসাব ধাপে ধাপে করবে।

Quick Revision:
সমান্তর ধারা: n তম পদ = a + (n - 1)d, সমষ্টি = n/2 {2a + (n - 1)d}; গুণোত্তর ধারা: n তম পদ = a × r^(n - 1); অসীম ধারার সমষ্টি = a/(1 - r), যখন |r| < 1।
