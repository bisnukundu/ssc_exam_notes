৭Unit 7 — দ্বিপদী বিস্তৃতি (পৃ. ১২৫–১৩৪)Unit
সহজ ব্যাখ্যা:
দ্বিপদী বিস্তৃতি হলো (a + b)^n-কে পদে পদে বিস্তৃত করে লেখা, যেমন (a + b)^2 = a^2 + 2ab + b^2। n যত বড় হয়, হাতে গুণ করে বিস্তৃত করা তত কঠিন হয়; তাই দ্বিপদী উপপাদ্য ব্যবহার করা হয়। বিস্তৃতির প্রতিটি পদের সহগ প্যাসকেলের ত্রিভুজ থেকে পাওয়া যায়, যেমন n = 3-এর জন্য সহগ 1, 3, 3, 1। (a + b)^n-এর বিস্তৃতিতে মোট (n + 1)টি পদ থাকে।

গুরুত্বপূর্ণ পয়েন্ট:
• দ্বিপদী উপপাদ্য: (a + b)^n = C(n,0)a^n + C(n,1)a^(n-1)b + C(n,2)a^(n-2)b^2 + ... + C(n,n)b^n, যেখানে C(n,r) = n! / (r!(n-r)!)।
• প্যাসকেলের ত্রিভুজ: n = 0: 1; n = 1: 1 1; n = 2: 1 2 1; n = 3: 1 3 3 1; n = 4: 1 4 6 4 1। প্রতিটি সংখ্যা তার উপরের দুটি সংখ্যার যোগফল।
• (n + 1) তম পদ থেকে (r + 1) তম পদের সাধারণ পদ: C(n,r) a^(n-r) b^r।
• (a - b)^n-এর বিস্তৃতিতে পদের চিহ্ন একান্তরভাবে + ও - হয়।

পরীক্ষার প্রস্তুতি:
MCQ-তে বিস্তৃতির পদের সংখ্যা, নির্দিষ্ট পদের সহগ ও প্যাসকেলের ত্রিভুজ থেকে প্রশ্ন আসে বেশি। (a + b)^n-এর পদসংখ্যা (n + 1), n নয় — এটা ভুলে যাওয়া যাবে না। (a - b)^n-এ চিহ্নের ধারা মনে রাখবে: প্রথম পদ ধনাত্মক, তারপর একান্তরভাবে ঋণাত্মক ও ধনাত্মক। সহগ বের করতে C(n,r)-এর সূত্রে ফ্যাক্টোরিয়ালের হিসাব সাবধানে করবে।

Quick Revision:
(a + b)^n-এর বিস্তৃতিতে (n + 1)টি পদ থাকে; সহগ প্যাসকেলের ত্রিভুজ থেকে পাওয়া যায় (n = 4-এর জন্য 1, 4, 6, 4, 1); সাধারণ পদ C(n,r) a^(n-r) b^r।
