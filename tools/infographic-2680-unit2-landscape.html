বীজগাণিতিক রাশি (ইউনিট-০২)

SSC-2680 • উচ্চতর গণিত

🧮

বহুপদ কী?

যে রাশিতে শুধু x-এর পূর্ণসংখ্যা ঘাত থাকে, তাকে বহুপদ বলে। বহুপদের মাত্রা = চলকের সর্বোচ্চ ঘাত। যেমন 3x3 + 2x-এর মাত্রা 3। উৎপাদকে বিশ্লেষণ মানে রাশিকে গুণনীয়কের গুণফল আকারে লেখা — x2 − 9 = (x − 3)(x + 3)।

📐 গুরুত্বপূর্ণ সূত্র

(a + b)2 = a2 + 2ab + b2বর্গের সূত্র
(a − b)2 = a2 − 2ab + b2বর্গের সূত্র
a2 − b2 = (a − b)(a + b)বর্গের অন্তর
a3 + b3 = (a + b)(a2 − ab + b2)ঘনের যোগফল
a3 − b3 = (a − b)(a2 + ab + b2)ঘনের অন্তর
x2 + 5x + 6 = (x + 2)(x + 3)মধ্যপদ বিভাজন

🔧 উৎপাদকে বিশ্লেষণের পদ্ধতি

১. সাধারণ উৎপাদকসব পদে থাকা উৎপাদক বের করা
২. সূত্র প্রয়োগউপরের সূত্রগুলো দিয়ে ভাঙা
৩. মধ্যপদ বিভাজনমাঝের পদকে দুই ভাগে ভাগ করা

📜 ভাগশেষ উপপাদ্য

f(x)-কে (x − a) দিয়ে ভাগ করলে ভাগশেষ f(a)f(a) = 0 হলে (x − a), f(x)-এর একটি উৎপাদক।
💡

সাধারণ ভুল: (a − b)2-এর সূত্রে মাঝের চিহ্ন বিয়োগ হয় — এটাই সবচেয়ে বেশি ভুল হয়। উৎপাদক ঠিক হয়েছে কি না গুণ করে যাচাই করবে।
