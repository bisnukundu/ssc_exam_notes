সমীকরণ (ইউনিট-০৩)

SSC-2680 • উচ্চতর গণিত

⚖️

দ্বিঘাত সমীকরণ

সমীকরণ হলো চলকসহ দুটি রাশির সমতা, যেমন 2x + 3 = 7। দ্বিঘাত সমীকরণের সাধারণ আকার ax2 + bx + c = 0, যেখানে D = b2 − 4ac নিশ্চায়ক।

🔍 নিশ্চায়ক D = b2 − 4ac — মূলের প্রকৃতি

D > 0দুটি ভিন্ন বাস্তব মূলধনাত্মক হলে দুটি আলাদা বাস্তব মূল
D = 0দুটি সমান বাস্তব মূলনিশ্চায়ক শূন্য হলে দুটি মূল একই হয়
D < 0বাস্তব মূল নেইনিশ্চায়ক ঋণাত্মক হলে কোনো বাস্তব মূল থাকে না

➕ মূলের যোগফল ও গুণফল

−b / aমূলদ্বয়ের যোগফল
c / aমূলদ্বয়ের গুণফল

📏 মূলের সূত্র

x = (−b ± √D) / 2aD = b2 − 4ac
💡

সাধারণ ভুল: নিশ্চায়ক বের করার সময় b-এর চিহ্নসহ বর্গ করবে; b ঋণাত্মক হলেও b2 ধনাত্মক হয়। সূত্রের −b অংশে চিহ্ন ভুল সবচেয়ে বেশি হয়।
