অসীম ধারা (ইউনিট-০৫)

SSC-2680 • উচ্চতর গণিত

♾️

ধারা কী?

ধারা হলো সংখ্যার একটি ক্রম, যেমন 2, 5, 8, 11, …। সমান্তর ধারায় পরপর দুটি পদের পার্থক্য সমান থাকে — সেই পার্থক্য সাধারণ অন্তর d। গুণোত্তর ধারায় পরপর দুটি পদের অনুপাত সমান থাকে — সেই অনুপাত সাধারণ অনুপাত r।

➕ সমান্তর ধারা

2, 5, 8, 11, …   d = 3
n তম পদ = a + (n − 1)dপ্রথম n পদের সমষ্টি = n/2 {2a + (n − 1)d}
VS

✖️ গুণোত্তর ধারা

2, 4, 8, 16, …   r = 2
n তম পদ = a × rn−1প্রথম n পদের সমষ্টি = a(rn − 1) / (r − 1), যেখানে r ≠ 1
অসীম গুণোত্তর ধারার সমষ্টি = a / (1 − r) শুধু তখনই, যখন |r| < 1
💡

মনে রাখবে: সূত্রে n-এর জায়গায় সঠিক সংখ্যা বসাবে — ১০ম পদের জন্য n = 10, (n − 1) = 9। অসীম ধারার সমষ্টির সূত্র শুধু |r| < 1 হলেই চলে।
