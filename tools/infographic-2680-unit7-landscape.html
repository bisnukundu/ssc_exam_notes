SSC-2680 • উচ্চতর গণিত

🔺

দ্বিপদী বিস্তৃতি কী?

(a + b)n-কে পদে পদে বিস্তৃত করে লেখা, যেমন (a + b)2 = a2 + 2ab + b2। n যত বড় হয়, হাতে গুণ করে বিস্তৃত করা তত কঠিন হয়; তাই দ্বিপদী উপপাদ্য ব্যবহার করা হয়।

📜 দ্বিপদী উপপাদ্য

(a + b)n = C(n,0)an + C(n,1)an−1b + … + C(n,n)bnযেখানে C(n,r) = n! / (r!(n−r)!)
মোট পদ: (n + 1)টি
সাধারণ পদ: (r + 1) তম পদ = C(n,r) an−r br
(a − b)n-এ: পদের চিহ্ন একান্তরভাবে + ও − হয়
💡

মনে রাখবে: (a + b)n-এর পদসংখ্যা (n + 1), n নয়। (a − b)n-এ প্রথম পদ ধনাত্মক, তারপর একান্তরভাবে ঋণাত্মক ও ধনাত্মক।
