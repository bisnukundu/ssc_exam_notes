Conditional Sentence (Unit-06)

SSC-2652 • English Second Paper

Zero

General truth

If + Present, Present

'If water is heated, it boils.'

Type 1

Real — future

If + Present, will + base verb

'If it rains, we will stay at home.'

Type 2

Unreal — present

If + Past, would + base verb

'If I were rich, I would help the poor.'
'were' is used with all persons.

Type 3

Unreal — past

If + had + pp, would have + pp

'If you had studied, you would have passed.'

Quick Revision:   Zero: if + present, present  •  Type 1: if + present, will  •  Type 2: if + past, would  •  Type 3: if + had + pp, would have + pp

⚠️

Common mistakes: never use 'will' in the if-clause — 'If it will rain' is wrong. In Type 3 use 'would have', not 'would'. First look at the tense of the if-clause, then choose the main clause to match it.
